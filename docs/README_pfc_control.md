## 1. 回路構成（.scicir から復元したネットリスト）

```
  VAC(+) ── L(350µH) ── IVS/iL(電流センス) ──┬── D1 ──┐
                                             └── Q1 ──┤
                                                      │
  VAC(−) ─────────────────────────────────┬── D2 ──┤ DC+ (400V)
                                            └── Q2 ──┤
                                                      │
                            DC+ ── C(1.2mF) ── GND,  IDC(1.25A): DC+ → GND
```

Q1・Q2 はどちらも GND へのローサイドスイッチ（デュアルブースト型ブリッジレスPFC）。

- **正の半周期**：Q1 が高周波PWM。帰路は Q2 のボディダイオード（Vonb = 1 V）
- **負の半周期**：Q2 が高周波PWM。帰路は Q1 のボディダイオード

| 素子 | パラメータ | 値 |
|---|---|---|
| VAC | Voltage / Frequency | 100 **Vrms**（Scideamの交流電圧源は実効値指定）／ 50 Hz |
| L | Inductance / Esr | 350 µH ／ 10 mΩ |
| C | Capacitance / Esr | 1.2 mF ／ 80 mΩ |
| Q1, Q2 | Ron / ボディダイオード | 100 mΩ ／ Vonb 1 V, Ronb 100 mΩ |
| D1, D2 | TurnOnVoltage / Ron | 700 mV ／ 100 mΩ |
| IDC | Current | 1.25 A（定電流負荷） |
| — | MainFrequency | 100 kHz |

**導通経路の等価定数**（フィードフォワードに使う）：

```
R_EQ  = L.Esr + Ronb + Ron = 10m + 100m + 100m = 0.21 Ω
V_RET = Vonb = 1.0 V          （帰路ボディダイオードの順方向電圧）
VF_D  = 0.7 V                 （昇圧ダイオード）
```
Q と D のオン抵抗が等しいので、`d*Ron + (1−d)*Ron_d` はデューティに依らず一定になる。

## 2. 制御構成

```
                                    ┌──────── 100 kHz（毎スキャン）────────┐
  Vbus ──[LPF 30Hz×2段]──► Vbus_f ──►(−)──► 電圧PI ──► Ipk_ref ──┐         │
                            (100Hz      ▲     (帯域 8 Hz)         │         │
                             リプル除去) Vref                      │         │
                                     (ソフトスタート)               ▼         │
  |vac| ─────────────────────► ÷Vpk ──► Templ ──►(×)──► i_ref ──┬──────┐   │
                                                                 │      ▼   │
                                       di_ref/dt = Ipk·ω·|cos| ──┼──►┌──────────────────────┐
                                                                 │   │ 完全FF               │
                                                                 │   │ D_ff = 1 −           │
                                                                 │   │ (|vac| − V_RET       │
                                                                 │   │  − R_EQ·i_ref        │
                                                                 │   │  − L·di_ref/dt)      │
                                                                 │   │ / (Vbus + VF_D)      │
                                                                 │   └──────────┬───────────┘
  i_r ──────────────────────────────────────►(−)◄──────────────┘              │
                                               │                               │
                                        誤差を毎スキャン積算                    │
                                               │                               │
                              ┌── 50 Hz（N_I=2000 スキャンに1回）──┐           │
                              │ 平均誤差 = Σe/N ──► 電流PI ──► D_pi │          │
                              └──────────────────────┬─────────────┘           │
                                                     ▼                         ▼
                                    D_pfc = clamp(D_ff + D_pi·Templ, 0, 0.995)
                                                     │
                         正の半周期 → Q1、負の半周期 → Q2（もう一方は帰路）
```

**要点**

- **正弦波整形はフィードフォワード（D_ff）が担当する。** よくある `d = 1 − |vac|/Vbus` は
  「インダクタ電流ゼロの平衡点」であって、これだけでは電流が流れない。
  `R_EQ·i_ref` と `L·di_ref/dt`、そして素子の導通降下こそが正弦波電流を作っている本体。
- **PI は平均電流誤差を補正する。** 毎スキャン（100 kHz）で誤差を積算し、電流ループの
  実行タイミングで平均してから PI に入れる。これが文字どおりの「平均電流制御」で、
  実行周波数を変えても同じコードがそのまま機能する。

## 3. サンプリング周波数の設計論（ご指定の 電流50Hz / 電圧100kHz について）

### 3.1 サンプリング周波数とループ帯域は別物

一般的な平均電流制御の教科書的な割り当ては「電流ループ＝スイッチング周波数、
電圧ループ＝商用周波数域」だが、**ご指定の割り当てでも成立する**。

**電圧ループ 100 kHz — 問題なし。**
サンプリング周波数を上げること自体は害がない。PFC の電圧ループで本質的に重要なのは
「帯域を商用周波数の 2 倍（100 Hz）より十分低くする」ことで、これはゲインの問題であって
サンプリング周波数の問題ではない。本実装では 100 kHz で毎スキャン実行しつつ、
交差周波数 7.75 Hz（位相余裕 46.6°、ゲイン余裕 16.3 dB）に設計し、
100 Hz リプルは 30 Hz LPF 2 段（−21 dB）で除去している。
実装上は「毎スキャン回る遅い PI」になるだけ。

**電流ループ 50 Hz — 成立するが役割が変わる。**
商用 1 周期に 1 回しかデューティを更新できないため、瞬時波形整形はできない。そこで

1. 瞬時の波形整形は **完全フィードフォワード** が担当（100 kHz で毎スキャン更新）
2. 50 Hz の PI は **1 商用周期の平均電流誤差＝電流振幅の誤差** を補正

という役割分担にしている。電流振幅の誤差（負荷変動、センサゲイン誤差、効率の変化）は
この 50 Hz ループが吸収する。

ただし **波形そのものの歪みは 50 Hz ループでは直せない**。フィードフォワードが
回路定数（特に L）に依存するため、L の設定値が実回路とずれると THD が悪化する（§6.2）。

### 3.2 電流ループ実行周波数の比較（`--sweep` の結果）

| F_ILOOP | 電流ループ交差周波数 | 力率 | 入力電流THD | Vbus | リプル |
|---:|---:|---:|---:|---:|---:|
| **50 Hz（指定値）** | 2.5 Hz | **0.9981** | **3.14 %** | 400.00 V | 3.37 Vpp |
| 500 Hz | 25 Hz | 0.9976 | 3.49 % | 400.00 V | 3.36 Vpp |
| 5 kHz | 250 Hz | 0.9993 | 2.02 % | 400.00 V | 3.31 Vpp |
| 100 kHz（教科書的ACMC） | 5 kHz | 0.9996 | 2.39 % | 400.00 V | 3.31 Vpp |

指定どおりの 50 Hz で **力率 0.998、THD 3.1 %**。電流ループを 100 kHz にしても
改善は 0.75 ポイント程度で、この回路では 50 Hz でも十分実用になる。
残る 3 % は主にゼロクロス歪み（帰路ボディダイオードの 1 V と、昇圧ダイオードが
逆流を阻止するため電流が負になれないことによる）。

参考：THD 3.1 % のとき第3高調波は基本波の約 2.5 %（5 A に対して 0.13 A）で、
IEC61000-3-2 Class A の第3高調波限度 2.30 A に対して十分な余裕がある。

### 3.3 PI 出力のテンプレート整形（`SHAPE_PI`）

F_ILOOP が低い場合、PI が出す**一定のデューティ補正**が商用 1 周期にわたって加わるため、
ゼロクロス付近で電流にオフセットが乗り歪みになる。そこで補正量を電流指令と同じ
正弦テンプレート `|vac|/Vpk` で整形してから加算している（`SHAPE_PI = 1`）。
F_ILOOP を 2 kHz 以上に上げる場合は `SHAPE_PI = 0`（素の瞬時ACMC）にすること。

## 4. ゲイン設計

ゲインはベタ書きせず、`pfc_acmc_sim.py` が交差周波数の指定から自動算出する。

```
PI(s) = Kp · (1 + 2π·fz / s)     離散実装では毎回 Ki·Ts を積む
```

### 4.1 電流ループ ★通常と設計則が違う

プラント（デューティ → 整流座標インダクタ電流）：

```
Gid(s) = (Vbus + VF_D) / (R_EQ + sL)
|Gid(2.5 Hz)| = 400.7 / |0.21 + j·2π·2.5·350µ| = 1907 A/duty
```

**ここで教科書どおりに `Kp = 1/|Gid(fc)|` としてはいけない。**
L/R_EQ の折点は 0.21/350µ = 95 Hz なので、fc = 2.5 Hz 付近ではプラントは**抵抗性**であり
`|Gid|` がほぼ平坦になる。すると開ループゲインが 2.5 Hz〜20 Hz にわたって 1 に張り付き、
誤差平均化＋ZOH の無駄時間（1.5·Ts = 30 ms）が位相 −180° を作る 13 Hz 付近で
**ゲイン余裕がほぼゼロ**になる（位相余裕だけ見ていると気づかない）。

そこで比例ゲインは次の 2 つの小さい方を採っている：

```
(a) 1 / |Gid(fc_i)|                      … 交差周波数で 0 dB
(b) 0.30 / |Gid(f180)|,  f180 = 1/(3·Ts) … ゲイン余裕 10 dB を確保
```

この回路では (b) が効き、PI ゼロは 0 dB 交差が fc_i に来るように自動計算される。

```
FC_I  = 2.500 Hz,  零点 = 7.822 Hz
KP_I    = 1.596016e-04
KI_I·Ts = 1.568842e-04      (Ts = 1/50 Hz = 20 ms)
→ 開ループ fc = 2.50 Hz、位相余裕 79.2°、ゲイン余裕 9.1 dB @ 13.1 Hz
```

`pfc_acmc_sim.py` はゲイン余裕も数値で出力するので、ゲインを触ったら必ず確認すること。

### 4.2 電圧ループ

電力平衡 `½·Vac_pk·Ipk = Vbus·i_bus` より、`Ipk → Vbus` は低周波では純積分器：

```
Gvi(s) = (Vac_pk / (2·Vbus)) / (sC)
|Gvi(8 Hz)| = (141.42/800) / (2π·8·1.2m) = 2.931 V/A
```

> **定電流負荷では負荷極が存在しない**ため、この式がそのまま成立する。
> 抵抗負荷なら `1/(RC)` の極が減衰を与えるが、定電流負荷にはそれが無い。
> したがって PI ゼロを上げすぎない（`fz = fc/4`）ほうが安全。

```
FC_V  = 8.000 Hz,  零点 = 2.000 Hz
KP_V    = 3.412134e-01
KI_V·Ts = 4.287814e-05      (Ts = 1/100 kHz = 10 µs)
A_VBUS  = 1.884956e-03      (= 2π·30 Hz / 100 kHz、1次LPF×2段)
→ 開ループ fc = 7.75 Hz、位相余裕 46.6°、ゲイン余裕 16.3 dB @ 27.9 Hz
```

```
Vbus mean = 400.15 V,  ripple 4.00 Vpp,  PF = 0.9899,  THD = 3.58 %
```

状態平均化モデルと同じ結論。力率が 0.998 → 0.990 に下がるのは

ピーク電流 7 A に対して 37 % と大きめなので、**EMI フィルタは必須**。
リプルを減らしたい場合は L を大きくするか fsw を上げる。
（L を大きくすると §6.2 の設定値誤差にも強くなる方向）

> このままだと整定前に終わる。**0.6 秒以上に延ばす**か、
> C の `InitialVoltage` を 400 にして 0.2 秒程度で確認すること。

## 6. 実装上の落とし穴（実測で確認したもの）

### 6.1 di_ref/dt は解析式で求める ★THD が 5.1 % → 3.1 % に改善

フィードフォワードには `L·di_ref/dt` が必要。これを「センシングした `|vac|` の差分＋LPF」
から作ると、**LPF の位相遅れがそのまま電流誤差になる**。2 kHz LPF の遅れ約 80 µs は
50 Hz で 1.4° に相当し、7 A × sin(1.4°) ≈ 0.17 A の誤差を生む。この誤差のせいで
ゼロクロスで電流が指令より先に 0 に到達し、昇圧ダイオードが逆流を阻止するため
そのまま 0 に張り付いて大きなクロスオーバ歪みになる。

`i_ref = Ipk·|sin|` なので `di_ref/dt = Ipk·ω·|cos|` であり、
`|cos| = sqrt(1 − Templ²)` と解析式で求められる。差分は**増減の符号判定にだけ**使う。

| di_ref/dt の求め方 | 力率 | THD |
|---|---:|---:|
| 差分＋2kHz LPF | 0.9959 | 5.13 % |
| **解析式 Ipk·ω·√(1−Templ²)** | **0.9981** | **3.14 %** |

### 6.2 インダクタンス設定値の誤差感度 ★電流ループ50Hzで最も重要

50 Hz の電流ループは瞬時波形を直せないため、波形整形はフィードフォワードの
`L_PFC` 設定値の精度に依存する。`--l-err` で実回路の L をずらしたときの THD：

| 実回路 L / 設定値 L_PFC | F_ILOOP = 50 Hz | F_ILOOP = 100 kHz |
|---:|---:|---:|
| 0.7 倍（設定値が過大） | **7.49 %** | 2.37 % |
| 0.8 倍 | 5.94 % | 2.37 % |
| 0.9 倍 | 4.48 % | 2.38 % |
| 1.0 倍 | 3.14 % | 2.39 % |
| 1.2 倍（設定値が過小） | 1.48 % | 2.41 % |

- **設定値が実際より大きい方向のずれが悪い。** 逆に設定値が小さめのずれはむしろ改善する。
  → `L_PFC` には**動作電流でのインダクタンス実測値、またはそれより小さめの値**を入れること。
  ダストコアやフェライトは電流ピークでインダクタンスが落ちる（直流重畳特性）ため、
  小信号 LCR メータの値をそのまま入れると「設定値が過大」側に振れて歪む。
- 電流ループを 100 kHz にすると **L の誤差にほぼ完全に鈍感**（どの条件でも THD 2.4 %）。
  これが「電流ループを速くする」ことの本質的な利点。

### 6.3 最大デューティ `D_MAX`

ゼロクロス付近では必要なデューティが 1 に張り付くため、`D_MAX` を下げると
`(1 − D_MAX)·Vbus` の逆電圧がインダクタに加わって歪みが増える。

| D_MAX | THD（電流50Hz） |
|---:|---:|
| 0.980 | 4.09 % |
| **0.995** | **3.14 %** |
| 1.000 | 3.02 % |

実機で最小オフ時間が必要な場合のみ下げること。

### 6.4 `output()` のモードは `"AVE"` にする

Scideam の `output("シンボル名","V"/"I", モード)` の第3引数。ヘルプに記載があるのは
`"AVE"`（メイン周期の代表点＝平均値）と `"FIN"`（＝最終値）の2つ。

**電流センシングは必ず `"AVE"`。** 平均電流制御が必要とするのは
「スイッチング1周期の平均インダクタ電流」であって瞬時値ではない。瞬時値を読むと
電流リプルの谷を読むことになり、真の平均より ΔI/2 低い値になる。この誤差は
デューティに比例して商用周期内で変動するため、そのまま電流歪みになる。

> 既存の [gate_control_bridgeless_pfc_psfb.sciprc](gate_control_bridgeless_pfc_psfb.sciprc) は
> `"inst"` と書かれているが、これはヘルプに記載が無い値。

### 6.5 バス電圧の平均化は必須

電圧ループを 100 kHz で回す場合、100 Hz リプルがそのまま電流振幅指令を変調して
3 次高調波になる。30 Hz LPF 2 段（100 Hz で −21 dB）を必ず入れること。
Scideam には配列が無いので、移動平均ではなく 1 次 IIR を 2 段にしてある。

### 6.6 帰路スイッチの同期整流（オプション）

`SYNC_RETURN = 1` にすると、PWM していない側のスイッチを常時 ON にして
ボディダイオードの 1 V 降下を無くせる。**入力電力 510.9 W → 506.3 W（約 4.6 W 改善）。**
THD はほぼ変わらない（3.14 % → 3.05 %）。使う場合は `V_RET` を 0 にすること。

Q1 と Q2 は別ノードのローサイドスイッチなので、両方 ON になっても
貫通経路はできない（L 経由で入力を短絡する＝充電フェーズそのもの）。

## 7. Scideam での確認手順

必ず**内側（電流）→ 外側（電圧）**の順に確認する。

0. **シミュレーション時間を 0.6 秒以上に。** C = 1.2 mF の充電に約 0.4 秒かかる。
   C の `InitialVoltage` を 400 にすれば 0.2 秒程度で済む。
1. **実行周波数の確認。** スクリプトの実行周波数が `MainFrequency` = 100 kHz、
   かつスクリプト先頭の `FS = 100e3` と一致していること。ここがずれると全ゲインがずれる。
2. **センサ換算の確認。** `Ir` と `Iref` を重ねて表示し、極性（`Half`）と
   `K_ISENSE` の符号が正しいかを最初に見る。追従していなければここを疑う。
3. **電流ループ。** `D_pi` が ±0.01 程度の小さい値で動いていれば正常。
   張り付いている場合は `L_PFC` / `R_EQ` の設定値が実回路とずれている。
4. **電圧ループ。** `Vbus_f2` が `VBUS_REF` に整定するか確認。
   発散・振動する場合は `KP_V` と `KI_V_TS` を半分ずつ下げる。
5. **応答を速くしたい場合。** `fc_v` を上げる（`--fc-v 12` など）。
   ただし `f_vfilt`（LPF）も一緒に上げないと位相余裕が減る。目安は `f_vfilt ≈ 4·fc_v`。

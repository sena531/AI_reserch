# ACライン電圧センシング ノイズ対策手順

**対象基板：** `回路レイアウト/kicad/buck_pfc.2`（実機。改版しない前提）
**制御コード：** `制御＿シミュレーション/mplab/program/closed_1103.c`（dsPIC33EP128GS808）
**症状：** VLsense / VNsense に広帯域ノイズが重畳し、正弦波が埋もれる。入力電圧を上げるとノイズも増大。
**制約：** **時間と予算の都合で基板の作り直しはできない。** 以下は全て「今ある基板でできること」。
**作成日：** 2026-11-06（回路図・PCB レイアウト調査済み）

> ⚠️ `buck_pfc`（無印）と `gaibu_pfc/PFC1` は**別基板**。センス回路の定数が同一で紛らわしいが、
> 座標もリファレンス番号も違う。本文書は **buck_pfc.2 のみ**を対象とする。

## 0. 調査で確定した事実

### 0-1. センシング回路

```
VL ─[L2 4.7uH EMIチョーク]─ VL' ─[R19 18k]─[R20 150k]─┬─ IC8  MCP6021(ボルテージフォロワ) ─ VL_sense
                              │                        ├─ R21 1.2k ── GND1
                              └─[L1 1mH]─ ILout ─ Q1/D  └─ C20 0.1uF ── GND1

VN ─[EMIチョーク]─ VN' ─[R23 18k]─[R24 150k]─┬─ IC10 MCP6021 ─ VN_sense
                                              ├─ R25 1.2k ── GND1
                                              └─ C30 0.1uF ── GND1
```

| 項目 | 値 |
|---|---|
| 分圧比 | 1.2 / (18 + 150 + 1.2) = **1/141** |
| フィルタ | R = 1.2k ∥ 168k = 1191.5 Ω、C = 0.1 µF → **fc = 1.34 kHz、1次のみ**（100 kHz で −38 dB） |
| バッファ | MCP6021（GBW 10 MHz、RRIO）、3.3 V 単電源 |
| デカップリング | C22 / C33（10 µF） |

### ✅ センス点は正しい

`VL'` / `VN'` は **EMIチョーク L2（4.7 µH）の後、ブーストインダクタ L1（1 mH）の前**。
L1 の出力側（`ILout` = Q1 ドレイン）からは取っていない。**ここは問題ない。**

### 0-3. 🎉 グランドは既に分離されている【重要】

B.Cu の GND1 ベタ：

| 領域 | x 範囲 |
|---|---|
| アナログ側 | 83.6 〜 **148.5** |
| 電力側 | **151.9** 〜 273.3 |

- **x = 150 を跨ぐ GND1 の配線は 1 本も無い**（全レイヤ確認済み）

→ **アナログ部と電力部のグランドは既に分離され、1 箇所で接続されている。**
→ **経路①（共通インピーダンス結合）は設計済みの対策が入っている。**
→ **ベタ切断テストは不要。やってはいけない。**

センス分圧の GND（R21 / R25 / C20 / C30 の下側、x ≒ 130〜135）は
アナログ島の中にあり、橋渡し点のすぐ近く。**基準電位の取り方も妥当。**

## 2. 第0段階：そのノイズは本物か（最優先・費用0）

CH1 と CH2 のスパイクが同じタイミング・同じ形なのは、**測り方を疑うべき典型**。

### 2-1. プローブのアーティファクト確認

- [ ] プローブ先端を**自分の GND リードに短絡**し、同じ位置・姿勢で基板の近くに置く
- [ ] それでスパイクが出れば、**その分は全部プローブのループが拾った電磁誘導**

> 標準ワニ口 GND リードは 10〜15 cm、ループ面積は数 cm²。
> 観測値（±200 mV 程度）はちょうどその桁。

### 2-2. 測定条件

- [ ] **帯域制限を 20 MHz に**（現状 `帯域 Full 200MHz`）
- [ ] ワニ口 GND をやめ、**スプリング GND** か**先端直はんだの同軸ピグテール**に
- [ ] プローブケーブルを**フェライトコアに 3〜4 回巻く** → 減ればコモンモード電流が原因
- [ ] VLsense と VNsense を**差動（CH1 − CH2 の MATH）**で見る

> buck_pfc.2 には **テストポイントパッド 14 箇所**と**ターレット端子 24 箇所**がある。
> BNC は廃止されているので、同軸ピグテールを直接はんだ付けできる。

### 2-3. 安全

- [ ] **絶縁トランス**を入れる、または**差動プローブ／絶縁プローブ**を使う

### 2-4. ADC ダンプ【最終的な真実】

- [ ] `closed_1103.c` で VL/VN の AD 変換結果をバッファに溜め、**UART／デバッガでダンプ**
- [ ] または DAC / PWM（フィルタ付き）で外に出して観測

**ここが綺麗なら、ハード対策は一切不要。**

## 3. 第1段階：結合経路の切り分け

| # | 経路 | 本件の評価 | 判定方法 |
|---|---|---|---|
| ① 共通インピーダンス | **対策済み（0-3）** | — |
| ② 静電結合（dv/dt） | **有力** | 母線電圧を上げるとノイズが増える |
| ③ 電磁結合（di/dt） | **有力（L1 近接、0-5）** | 負荷電流を増やす／配線を動かすと変化 |

- [ ] **AC 印加 + ゲート停止** → 綺麗なら 100 % スイッチング起源
- [ ] **母線電圧を段階的に上げる（負荷一定）** → 電圧に比例 → **②**
- [ ] **母線電圧一定 + 負荷電流を変える** → 電流に比例 → **③**
- [ ] **センス線を動かす／L1 の向きを変える** → 変化 → **③**
- [ ] 念のため **F.Cu GND1 の橋渡し点（x 142〜160, y 72〜80）の両側**の電位差を差動で見る
      → ここが揺れていれば①が残っている

### SNR で評価する

分圧比 1/141 なので、

| 入力 | VLsense 振幅 |
|---|---|
| Vin = 15 V（低電圧試験時） | 約 0.11 Vpk ← ノイズ ±0.2 V に埋もれる |
| Vin = 141 Vpk（定格） | 約 1.00 Vpk ← 比が約 10 倍改善 |

**低電圧で試験しているから最悪の SNR を見ている可能性が高い。**

## 4. ハード側でできること（改版なし）

### 4-1. センス線のツイストペア化【費用ほぼ0】

- [ ] VL_sense とそのリターン（アナログ島の GND）を**ツイストペア**にする
- [ ] VN_sense も別の 1 組。**1 本の GND 線を分岐させない**
- [ ] またはシールド線で、**シールドは制御基板側の 1 点だけ接地**
- [ ] ケーブルを**電力段（x > 150 の領域）の真上に通さない**

### 4-2. ゲート抵抗を上げる【最も効果が速い】

現状 PFC 側 **R11 / R13 = 4.7 Ω**（オン側と思われる速いほう）、R12 / R14 = 22 Ω。

- [ ] **4.7 Ω を 10〜22 Ω に載せ替える**。dv/dt が下がればノイズは比例して減る
- [ ] PSFB 側（R15 / R17 = 6.8 Ω）も同様。**`Q6_S` が残る最大の dv/dt 源**なのでここが効く
- [ ] 代償はスイッチング損失。効率を測りながら決める

> Q1〜Q6 は CoolMOS **CFD7（高速ボディダイオード版）**。
> ボディダイオードの逆回復が速いので、ゲート抵抗を上げても逆回復起因のノイズは増えにくい。

### 4-3. CM クランプダイオード 2 本【空中配線で可】

デュアルブースト・ブリッジレス PFC は、非導通側の AC 端子が
**L1 + ボディダイオード経由でしか DC− に繋がらない**ため、構造的にコモンモードが大きい。

```
VL' ──[カソード(帯)  D_a  アノード]── GND1(DC−)
VN' ──[カソード(帯)  D_b  アノード]── GND1(DC−)
```

**アノード（帯のない側）を GND1 へ。** 逆にすると母線を短絡して破損する。

| 項目 | 値 |
|---|---|
| 逆電圧 | ライン電圧ピーク（AC100V で 141 V）。**600 V 品**を推奨（他部品と揃う） |
| 平均電流 | `I_F(AV) = I_pk / π` = 7.5 / π ≒ **2.4 A** |
| 実効電流 | `I_pk / 2` = **3.75 A** |
| 損失 | `V_F × I_pk / π` ≒ **2.4 W / 個** |
| 速度 | **標準整流品でよい。** 転流は線周波数のみ。高速品は V_F が高く逆効果 |

**部品：**
- 効果確認（I_pk ≤ 2 A の軽負荷）：**1N4007 ×2**（手持ちで即試せる）
- 本採用：**600 V / 8 A 以上の単相ブリッジモジュール 1 個**
  → `−` を GND1、`AC1` を VL'、`AC2` を VN'、**`+` は開放・絶縁**
  （内部の「− → AC」2 素子がそのままクランプダイオードになる）

**通電前の確認（必須）：** DMM ダイオードモードで**黒を GND1、赤を VL'** → **OL なら正常**。
0.5 V 前後が出たら逆向き。
（赤を GND1 側にした順方向テストは、ボディダイオード経由の経路があるので判定に使えない）

**副作用：** 戻り経路に V_F が入り、2.4 W × 2 = 4.8 W。480 W に対し **約 1 % の効率低下**。
文献上も確立した構成（AC側クランプダイオード付きデュアルブースト）なので、研究報告に書ける。

### 4-4. センス回路のフィルタを 2〜3 次に【部品載せ替え】

必要な帯域は 50 Hz + 高調波 + ゼロクロスで **せいぜい 1〜2 kHz**。遠慮なく落としてよい。

| 位置 | 追加 | 効果 |
|---|---|---|
| IC8 / IC10 の pin3 直近 | 100 Ω + 1 nF | オペアンプ入力の RF 整流を防ぐ |
| pin2–pin6 間（現状は直結） | 10 kΩ を挿入し並列に 10 nF | 2 次目の極（fc ≒ 1.6 kHz） |
| 出力 → コネクタ間 | 1 kΩ + 100 nF | 3 次目の極 |
| 制御基板の ADC ピン直近 | 1 kΩ + 100 nF | 最終防壁 |

3 次 1.5 kHz なら 100 kHz で約 **−110 dB**。

**電源の余裕に注意：** 400 V / 141 = 2.84 V に対し電源 3.3 V。余裕 0.46 V しかない。
過渡でクリップする恐れがあるなら **R21 / R25 を 1.0 kΩ に下げる**（1/169、400 V → 2.37 V）。

### 4-5. L1 とセンス抵抗の磁気結合（③が出た場合）

L1（139.2, 49.85）と R20（134.79, 75.36）の距離は約 26 mm。

- [ ] L1 を**物理的に動かす／立てる向きを変える**（巻線の軸をセンス回路に向けない）
- [ ] L1 とセンス回路の間に**金属板（アルミ・銅）を立てて片側だけ接地**
- [ ] 改版できないので、**まず向きの最適化**で効果を見る

## 5. ソフト側でできること（費用0・最優先）

### 5-0. 現状の ADC 設定（確認済み）

| 項目 | 設定 |
|---|---|
| スイッチング | 100 kHz（`PTPER = PERIODmax = 9600`、1 count = 1.0417 ns） |
| ADC トリガ源 | AN0〜AN4, AN11 すべて `TRGSRC = 0x08`（**PWM4**） |
| トリガ位置 | **`TRIG4 = 2400`（周期の 25 %）** |
| PWM4 | 変調しないダミー。**ADC トリガ専用でゲートを駆動しない** |
| `TRIG1/2/3 = 0` | **残骸**。PWM1/2/3 を使う行は全てコメントアウト済み。実害なし |

**→ 同期サンプリングの基本は既に入っている。**
AN0〜AN3 は専用コアなので **VL_sense と VN_sense は完全同時サンプリング**され、
`Vac = ADCBUF0 - ADCBUF1` / `Vrec = ADCBUF0 + ADCBUF1` の差動が正しく成立している。

**残る穴：固定の 2400 を、動くエッジが横切る。**

| エッジ | 位置 | 動くか |
|---|---|---|
| PFC ターンオン | `0` | 固定（安全） |
| **PFC ターンオフ** | `Wout`（PDC1/PDC2） | **線周期で掃引。`Wout ≒ 2400` で衝突** |
| PSFB leg A | `0`, `PDC6 ≒ 4800` | ほぼ固定 |
| **PSFB leg B** | `wPhase`, `wPhase + PDC7` | **位相指令で掃引。`wPhase ≒ 2400` で衝突** |

`Q6_S`（1144 mm²）が残る最大の dv/dt 源なので、**leg B のエッジが乗った瞬間が最悪。**

### 5-1. メディアンフィルタ【最優先・リスク最小】

VL/VN は **1.34 kHz のフィルタを通った 50 Hz 信号を 100 kHz でサンプリング**している。
**線周期あたり 2000 サンプル。** 帯域が 2000 倍余っているので、メディアンのコストは事実上ゼロ。

**最大の効能：極性判定の保護。**
`half` は `Vac` のヒステリシス判定で決まる。スパイクで極性が反転すると整流座標の電流の符号が逆になり、
**負帰還が正帰還に変わる**。症状は「デューティが上限に張り付く」「ゲート幅が不規則」で、
**観測されている Q1GS のパルス幅の乱れと一致する。**

```c
/* ---- median of 3 (near the top of the file) ---- */
static inline int med3(int a, int b, int c)
{
    if (a > b) { int t = a; a = b; b = t; }  /* now a <= b */
    if (b > c) { b = c; }                    /* b = min(b, c) */
    return (a > b) ? a : b;                  /* max(a, min(b,c)) */
}

/* ---- in _ADCAN2Interrupt, replace the Vac / Vrec lines ---- */
{
    static int vl_h[3] = {0,0,0};
    static int vn_h[3] = {0,0,0};
    static unsigned char hi = 0;
    int vl, vn;

    vl_h[hi] = (int)ADCBUF0;
    vn_h[hi] = (int)ADCBUF1;
    if (++hi >= 3) { hi = 0; }

    vl = med3(vl_h[0], vl_h[1], vl_h[2]);
    vn = med3(vn_h[0], vn_h[1], vn_h[2]);

    Vac  = vl - vn;    /* signed : polarity decision */
    Vrec = vl + vn;    /* |vac|  : multiplier and feed-forward */
}
```

- コスト約 20 命令（60 MIPS / 10 µs = 600 命令の 3 %）
- 群遅延 1 サンプル = 10 µs → 50 Hz に対し **0.18°**。無視できる
- ピーク保持（`vl_pk_run`）も `vl` を使うよう直す

> **⚠️ 電流帰還 `Iin` にはかけないこと。** 電流ループの交差は 3333 Hz。
> 10 µs の遅れは **12° の位相余裕**を食う。かけるなら余裕を計算し直してから。

### 5-2. ADC トリガを duty 追従に

PFC の**オン期間の中央**なら、ターンオン（`0`）とターンオフ（`Wout`）の両エッジから常に最大距離。

```c
/* ---- defines ---- */
#define TRIG_LO   960                   /* 1.0us after turn-on : clear the ringing */
#define TRIG_HI   (PERIODmax - 1920)    /* 2.0us before wrap   : let conversion finish */

/* ---- right after the PDC1 / PDC2 assignment ---- */
{
    int trg = (int)Wout >> 1;           /* middle of the ON time */
    if (trg < TRIG_LO) { trg = TRIG_LO; }
    if (trg > TRIG_HI) { trg = TRIG_HI; }
    TRIG4 = (unsigned int)trg;
}
```

**PWM4 はゲートを駆動していない**ので、`TRIG4` を動かしてもスイッチング動作に影響しない。

**動作範囲：** `D = 1 − |vac|/Vdc`。`Vdc = 200 V`、`Vpk = 141 V` なら `D_min = 0.295`
→ `Wout_min = 2832` → `trg = 1416`。零クロス付近では `trg → 4800`。
**通常運転では 1400〜4800 に収まり、クランプは安全網としてしか効かない。**

#### ⚠️ クランプを絶対に外さない

カウンタが到達しない値を書くと **ADC トリガが出ず `_ADCAN2Interrupt` が来なくなる**。
100 kHz の制御が丸ごと止まり、PDC は直前の値のまま残る。
**ゲートは止まらないのに制御だけ死ぬ**という最悪の状態になる
（コード中にも同趣旨の注意書きがある）。

### 5-3. PSFB エッジからの退避（任意）

```c
#define EDGE_GUARD  480                 /* 0.5us */
if (trg > (int)wPhase - EDGE_GUARD && trg < (int)wPhase + EDGE_GUARD) {
    trg = (int)wPhase + EDGE_GUARD;
    if (trg > TRIG_HI) { trg = TRIG_HI; }
}
```

5-1 のメディアンが入っていればたまの衝突は弾けるので、**まず 5-1 + 5-2 で様子を見る**。

### 5-4. 瞬時値を直接使うのをやめる【構造的な解】

電流指令を「`Vrec` の瞬時値 × `Ipk`」で作っていると、**Vrec のノイズがそのまま指令のノイズになる。**

1. `Vac` から **PLL（SOGI-PLL など）で位相 θ だけを抽出**
2. 電流指令は**内部生成の `sin θ`** から作る

PLL は積分器を含むためスパイクに極めて鈍感。**センシングの要求精度そのものが下がる。**
ゼロクロス検出も θ から取る。

## 6. 改版が必要で、今回は見送る項目（記録のみ）

次に基板を起こすときのために残しておく。

## 調査で解消した項目

- ~~センス点がスイッチングノード側から取られている疑い~~
  → **否定。** `VL'`/`VN'` は EMIチョーク後・L1 前で正しい
- ~~アナログ部と電力部の GND ベタが全面接続されている疑い~~
  → **否定。buck_pfc.2 は x ≒ 150 で分離され、F.Cu の島 1 箇所で接続されている**
- ~~ADC トリガがスイッチングエッジ上にある疑い（`TRIG1 = 0`）~~
  → **否定。** 全 ADC チャネルは PWM4 トリガで `TRIG4 = 2400`（周期の 25 %）
- ~~単電源オペアンプで負電圧がクリップされている疑い~~
  → **否定。** デュアルブースト構成では非導通側がボディダイオードで GND1 にクランプされる

## 電流ループ

### 伝達関数

昇圧チョッパのインダクタ電流は、スイッチング周期平均で見ると

```
L · di/dt = |vac| − (1 − d) · Vdc
```

`d` を微小変化させたときの応答を取ると、`|vac|` の項は消えて

```
P(s) = di/dd = Vdc / (s · L)        [A / duty]
```

**積分器が 1 つある**（インダクタ自身）ことが重要。ここに PI を足すと原点に極が 2 つになるので、
零点を交差周波数より十分下に置かないと位相余裕がなくなる。

降圧形なら `Vdc` の代わりに入力電圧が入る。式の形は同じ。

### ゲインの決め方

PI を `C(s) = Kp · (s + ωz) / s` と書く。交差周波数 `ωc` を `ωz` より十分上に取るなら、
その付近では `|C| ≒ Kp` なので

```
|C · P| = Kp · Vdc / (ωc · L) = 1
→  Kp = ωc · L / Vdc = 2π · fc · L / Vdc
```

零点の位置は位相余裕で決める。`ωz = ωc/k` のとき、PI が交差周波数で稼ぐ位相は
`atan(k)` − 90°。

| k = fc/fz | 位相余裕への寄与 |
|---|---|
| 2 | 63° − 90° = −27° |
| 5 | 79° − 90° = −11° |
| 10 | 84° − 90° = −6° |

`k = 5` が実用上の落としどころ。これより零点を下げると低域のゲインが落ちて、
商用周波数での追従誤差（＝電流波形の歪み）が増える。

### 交差周波数の上限

- **サンプリング遅れ**：1 周期の計算遅れ＋ゼロ次ホールドで、`fc` において
  おおよそ `1.5 · 360° · fc/fs` の位相遅れが出る。`fc = fs/20` で 27°
- **スイッチングリプル**：`fc` を上げるとリプル成分がループを回って不安定になる

実用域は `fs/40 〜 fs/20`。100 kHz なら 2.5〜5 kHz。

**ただしこれは出発点であって結論ではない。** よく見る「`fc = fs/10`」という経験則は、
遅れを入れて計算すると位相余裕が 25° 程度しか残らないことがある。
**必ず数値で検証すること**（次節）。

## 設計を検証する

経験則で係数を出したら、**位相余裕と ゲイン余裕を実際に計算する**。
`scripts/gains.py --verify` がやってくれるが、中身を理解しておくと判断できる。

### 一巡伝達関数

```
L(s) = C(s) · P(s) · D(s)
```

- `C(s) = Kp (s + ωz)/s` — PI
- `P(s) = Vdc/(sL)` — プラント
- `D(s) = e^(−s·Td)` — **遅れ**。これを忘れると設計が楽観的になる

### 遅れの中身

| 要因 | 量 |
|---|---|
| 演算遅れ（サンプル → PWM 反映） | 1·Ts |
| ゼロ次ホールド | 0.5·Ts |
| 電流センスの RC / センサ帯域 | 実測で |

**合計 1.5·Ts が最低ライン。** PWM の更新がバッファされてさらに 1 周期遅れる構成なら 2.5·Ts。
`Td = 1.5·Ts` として `fc` での位相遅れは

```
Δφ = −360° · Td · fc
```

`fs` = 100 kHz、`fc` = 5 kHz なら −27°。`fc` = 2.5 kHz なら −13.5°。

### 判定の目安

| 指標 | 目安 |
|---|---|
| 位相余裕 PM | **45° 以上**（50〜60° が気持ちよい） |
| ゲイン余裕 GM | **6 dB 以上**（10 dB 欲しい） |
| 遅れ余裕 | `Td` が設計値の **2 倍**になっても安定か |

遅れ余裕を見ておくと、「電流センスに RC を足したら発振した」という事故を防げる。
センサ帯域やフィルタのポールは **`fc` の 20 倍以上**に置く。

### 動作点を振って確認する

1 点で OK でも、動作範囲の端で崩れていては意味がない。最低限この組み合わせを確認する。

- `Vdc` の最小・最大（プラントゲインが変わる）
- 入力電圧の最小・最大
- **負荷の最小（軽負荷）** — DCM に入る領域。ここは別物として扱う

電圧ループなら負荷抵抗がプラントの極を動かすので、**負荷 10 % と 120 %** の両端で確認する。

### 固定小数点で時間領域も見る

周波数領域で OK でも、整数化した係数で実際に回すとオーバーフローや
死にゾーン（`references/fixed-point.md` の (a)）で挙動が変わる。

Python で 20 行ほどのシミュレーションを書いて、

- ステップ応答の立ち上がり時間とオーバーシュート
- `int32` のオーバーフロー回数（0 であること）
- 積分器が動いているか（`Ui` が増えるか）

を確認すると、実機に持っていく前に潰せる。**実機でしか分からないのは校正値だけ**にしておく。

### 商用周波数での追従誤差

PFC の電流指令は商用周波数（50/60 Hz）で振れる。そこでのループゲインが

```
|T(j·2π·f_line)| = Kp · ωz · Vdc / ((2π·f_line)² · L)
```

これが十分大きくないと、電流が指令に追いつかず波形が歪む。
フィードフォワードを併用すると、PI が受け持つ量そのものが減るのでこの要求が緩む。

## 電圧ループ

### 伝達関数

入力電力の平均は、入力電流を `i = Ipk · |vac|/Vac_pk · sign` とすると

```
Pin = Vac_pk · Ipk / 2
```

出力コンデンサのエネルギー収支から

```
C · Vo · dVo/dt = Pin − Pout
```

`Ipk` まわりで線形化して

```
P(s) = dVo/dIpk = Vac_pk / (2 · Vo · C · s)
```

ここでも積分器が 1 つ（コンデンサ）。PI を足すので零点が要る。

### ゲインの決め方

```
G0   = Vac_pk / (2 · Vo · C)
Kp_v = 2π · fc_v / G0
Ki_v = Kp_v · 2π · fz_v        （fz_v ≒ fc_v）
```

電圧ループは移動平均の窓（= 商用 1 周期）ごとにしか更新されないので、
離散化の刻みは `T_v = 1/f_line` であって `1/fs` ではない。
増分形の係数に入れる `T` を間違えないこと。

```
A_v = Kp_v + Ki_v · T_v / 2
B_v = Kp_v − Ki_v · T_v / 2
```

### 交差周波数の上限

**2×f_line のリプルを通さないこと**が制約になる。移動平均でリプル自体は消えているが、
ループが速いと平均値の変動（負荷変動）に対して `Ipk` が速く動き、
乗算器を通って電流波形を歪ませる。

`fc_v = f_line/10 〜 f_line/25`（50 Hz なら 2〜5 Hz）。

遅いので負荷急変時の出力電圧変動は大きい。これは PFC の原理的な制約で、
出力コンデンサを大きくする以外に手はない。

### 出力リプルの見積もり

定電流負荷なら

```
ΔVo_pp = 2 · Io / (ω2 · C)        ω2 = 2π · (2 · f_line)
```

係数 2 を忘れると**半分に見積もる**ことになる。「2 乗平均ではなく山から谷まで」である点に注意。

## 乗算器のスケーリング

`Iref = |vac| × Ipk` を整数でやるとき、`Ipk` の単位を何にするかで見通しが変わる。

```
Iref[ADCカウント] = (Vrec[ADCカウント] × Ipk[乗算器単位]) >> SH_MUL
```

`Vrec` が入力ピークのとき `Iref` が電流ピーク指令になってほしいので

```
Ipk[乗算器単位] = Ipk[A] × ADC_per_A × 2^SH_MUL / Vrec_pk
```

`SH_MUL` は、`Vrec × Ipk` が `int32` に収まる範囲で大きく取る。分解能が上がる。

**電圧ループの出力をこの単位で持つ**と、ISR で余計な変換をしなくて済む。
その分、電圧ループのゲイン換算にこの係数が入る。

## 位相シフトフルブリッジ

### 静特性

漏れインダクタンス `Llk` による転流期間を考慮した出力電圧は

```
Vo = Vdc² · D1² · Ts / ( n · Vdc · D1² · Ts + Llk · Io )
```

`D1 = φ/(2π)`、`φ` は位相シフト角。`D1` について解くと

```
D1 = sqrt( Vo · Llk · Io / ( Ts · Vdc · (Vdc − n·Vo) ) )
```

### 読み取り方

- **`(Vdc − n·Vo)` が分母にある**：中間電圧が出力電圧の n 倍に近づくと必要な位相が発散する。
  つまり伝送能力がゼロになる
- 逆に言うと、**軽負荷では `Vdc ≒ n·Vo` に落ち着く**。中間電圧はブリッジが出力電圧の n 倍に
  クランプしていると考えてよい
- `Io` が増えるほど必要な `D1` が大きくなる。定格で `D1` を決めておくと、軽負荷では余裕がある

### センタータップ整流の巻数比

式に入る `n` は **一次巻数 ÷ 二次片側巻数**。
総巻数で数えた値ではないので、設計値と実物を照合するときに取り違えないこと。

### 無負荷での発散

`Vdc ≒ n·Vo` ということは、**出力電圧が上がれば中間電圧が n 倍で追随する**。
無負荷で前段から電力を入れ続けると、出力コンデンサが充電され続けて両方とも上がり、
止まる要因がない。

開ループで電流指令を与えるなら、**必ず負荷を接続してから**。
抵抗負荷なら `Vo = sqrt(Pin · R)` で自然に釣り合うので、立ち上げに向く。
定電流負荷は低電圧域で最低動作電圧を割るので、立ち上げには使いにくい。

閉ループにすれば出力電圧が規定されるので、中間電圧も `n · Vo_ref` 付近に固定される。
**耐圧の心配を構造的になくす一番の方法は、電圧ループを閉じること。**

## 動作点が変わるとどうなるか

設計は定格点で行うが、立ち上げでは定格から遠い点を通る。何が変わるかを押さえておく。

| 動作点 | 電流ループ `P = Vdc/(sL)` | 影響 |
|---|---|---|
| 中間電圧が低い（立ち上げ中） | ゲインが**低下** | ループが遅くなる。安全側 |
| 中間電圧が高い | ゲインが**上昇** | 余裕が減る。定格で設計していれば問題ない |
| 軽負荷 | **DCM に入る** | 平均電流制御の前提が崩れる。1 点サンプリングが平均を表さない |

**DCM が一番やっかい**。ゲインの問題ではなく、フィードバック量そのものが意味を失う。
軽負荷で挙動が理解できないときは、まず CCM にいるかどうかを確かめること。

CCM の条件（昇圧）は

```
Io > (1 − D) · D · Vdc · Ts / (2 · L)
```

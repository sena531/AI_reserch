ブリッジレス PFC ファーム firmware/src/main_closed_loop.c の 2 つのゲイン設定（GAIN_SAFE = 1 立ち上げ用 / 0 通常）について、回路定数がずれたときにも発振しないかを比較した。

結論
立ち上げ用ゲインは、最悪条件でも 位相余裕 66° 以上・ゲイン余裕 15 dB 以上 で、発振の心配はない。 通常ゲインは電流ループが最悪条件で 位相余裕 34°・ゲイン余裕 4.9 dB まで下がるので、校正が済むまでは立ち上げ用で回す。

1. 制御の構成

外側の電圧ループが電流の振幅 Ipk を決め、入力電圧の形 |vac| を掛けて電流指令 Iref を作る。内側の電流ループがその指令にインダクタ電流を追従させる。太字が各ループの交差周波数（立ち上げ用 / 通常）。

2. 立ち上げ用と通常の比較

安定性と応答の速さはトレードオフ。立ち上げ用は余裕を取るかわりに応答が遅い。

3. 安定余裕の比較

塗りつぶし = 公称条件、斜線 = 最悪条件。点線が一般的な目安（位相余裕 45°、ゲイン余裕 6 dB）。

位相余裕 [°]
ゲイン余裕 [dB]
位相余裕とはループゲインが 1（0 dB）になる周波数で、位相が −180° まであと何度あるか。小さいほど応答が振動的になり、0° で発振する。
ゲイン余裕とは位相が −180° になる周波数で、ゲインをあと何 dB 上げると 0 dB に届くか。回路定数のずれでゲインが増えたときの余裕。
最悪条件とは電流ループは Vcs 250 V・L 0.7 mH・遅れ 2.5 Ts、電圧ループは C 4.8 mF・入力 115 Vrms。ループゲインと遅れが最も大きくなる組み合わせ。

7. 計算の前提

  • 一巡伝達関数 L(s) = (Kp + Ki/s) · P(s) · e−s·td。PI のゼロは交差周波数の 1/5。
  • 電流ループ：P(s) = Vcs / (s·L)。公称 Vcs 220 V・L 1 mH・遅れ 1.5 Ts（Ts = 10 µs）。
  • 電圧ループ：P(s) = Vac_pk / (2·Vo·C·s)。公称 入力 100 Vrms・Vo 48 V・C 6 mF（3 mF × 2）・遅れ 30 ms（20 ms 移動平均 ＋ 更新 1 周期分）。
  • 連続時間モデルにむだ時間を掛けて離散化の遅れを表した。交差周波数付近の評価は十分正確（ナイキスト周波数の近くでは少しずれる）。
  • 負荷急変時の電圧の振れは ΔV ≈ ΔIo / (2π·fc·C) による目安。
